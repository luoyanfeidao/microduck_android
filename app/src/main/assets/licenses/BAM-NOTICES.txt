equations, MuJoCo actuator conversion, deterministic 7.4 V / 0.1 sag profile,
single simulation-worker ownership, switchable XML baseline, explicit torque-off
and reset handling. Python/BAM/PyTorch are not runtime dependencies of this APK.
Parameter and reference-source hashes are recorded in BAM.lock.json in the source repository.
